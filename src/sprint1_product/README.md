Clone or download the repo\
Install all libraries specified by requirements.txt:\
`pip install -r requirements.txt`

Install scikit-surgeryutils:\
`python -m pip install scikit-surgeryutils`

Change directory into hand-eye-calibration:\
`cd hand-eye-calibration`

Run application with run_hand_eye_calibration.py:\
`python run_hand_eye_calibration.py`
